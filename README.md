# 📝 CRUD Application

A simple **CRUD (Create, Read, Update, Delete) Application** built using **Next.js** to learn and understand full-stack application development concepts.

## ✨ Features

- ➕ Create new records  
- 📖 Read and display data  
- ✏️ Update existing records  
- ❌ Delete records  


## 🛠️ Technologies Used

- **Next.js**
- **React.js**
- **JavaScript**

## 🎯 Purpose

This project was developed to **learn and practice CRUD operations using Next.js**.
